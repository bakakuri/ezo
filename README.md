## გაშვება: GitHub → Supabase → Vercel

რიგი მნიშვნელოვანია: ჯერ კოდი GitHub-ზე, მერე ბაზა Supabase-ში, ბოლოს საიტი Vercel-ზე.
სულ ~30 წუთი. ყველაფერი ტელეფონიდან კეთდება (Termux + Chrome).

### 1. GitHub — კოდის ატვირთვა Termux-იდან

**ერთხელ** (თუ აქამდე არ გაგიკეთებია):
```sh
pkg update -y && pkg install -y git gh unzip
termux-setup-storage          # „Allow“ — Termux-ს Downloads-ზე წვდომა
gh auth login                 # GitHub.com → HTTPS → Yes → Login with a web browser (კოდს ბრაუზერში ჩაწერ)
git config --global user.name "bakakuri"
git config --global user.email "შენი-GitHub-ის-ელფოსტა"
```

**პირველი ატვირთვა** (რეპო `bakakuri/ezo` ჯერ ცარიელია). `ezo.zip` ჩამოტვირთე — ჩავარდება Downloads-ში:
```sh
cd ~
ls ~/storage/downloads | grep ezo           # შეამოწმე სახელი (თუ „ezo (1).zip“-ა — ქვემოთაც ის ჩაწერე)
[ -d ezo ] && mv ezo ezo-old-$(date +%s)    # ძველი ასლი გვერდზე გადადის, არაფერი იშლება
mkdir ezo && cd ezo
unzip -q ~/storage/downloads/ezo.zip
ls -a                                       # უნდა ჩანდეს: .github api public scripts src supabase tests …
git init -b main
git add -A
git commit -m "ეზო — სრული ვერსია"
git remote add origin https://github.com/bakakuri/ezo.git
git push -u origin main
```

**შემდეგი განახლებები** (ჯერ Downloads-იდან ძველი `ezo.zip` წაშალე, რომ ახალი იმავე სახელით ჩამოვიდეს):
```sh
cd ~/ezo
unzip -o -q ~/storage/downloads/ezo.zip
git add -A
git commit -m "განახლება"
git push
```
push-ის შემდეგ Vercel თავისით აწყობს ახალ ვერსიას, GitHub Actions კი ტესტებს უშვებს („Actions“ ჩანართი).

### 2. Supabase — ბაზა, ფუნქციები, ავტორიზაცია

**2.1 ადგილი უფასო გეგმაზე.** უფასოდ ერთდროულად მხოლოდ 2 აქტიური პროექტია. თუ ორი უკვე გაქვს,
ერთი დააპაუზე: პროექტი → Project Settings → General → **Pause project** (მონაცემები რჩება, ნებისმიერ დროს აღადგენ).

**2.2 ახალი პროექტი.** supabase.com/dashboard → **New project** → Name: `ezo` → Database Password: **Generate**
(შეინახე სადმე) → Region: **Central EU (Frankfurt)** (საქართველოსთან ყველაზე ახლოს) → Create. 1–2 წუთს ელოდები.

**2.3 გაფართოებები.** Database → Extensions → ჩართე **pg_cron** და **pg_net**.

**2.4 სქემა.** SQL Editor → **New query** → ჩასვი `supabase/schema.sql` მთლიანად → **Run**.
- ტელეფონზე მარტივად დასაკოპირებლად: Chrome-ში გახსენი `github.com/bakakuri/ezo/blob/main/supabase/schema.sql`
  და დააჭირე **Copy raw file** (ორი კვადრატის ხატულა ფაილის თავზე).
- თუ მთლიანი ფაილი არ ჩაჯდა ან ბრაუზერი გაიჭედა — გაუშვი ნაწილებად, თანმიმდევრობით, თითო ახალ query-ში:
  `supabase/parts/schema-1.sql` → `schema-2.sql` → `schema-3.sql` → `schema-4.sql`.
- თუ გამოვა გაფრთხილება „destructive operation“ — ეს ფაილის `drop policy if exists`-ებია, დააჭირე **Run this query**.
- შედეგი: „Success. No rows returned“. Table Editor-ში გამოჩნდება ცხრილები (profiles, posts, games…).
- ფაილი ხელახლა გაშვებადია: ყოველი ახალი ვერსიის შემდეგ უბრალოდ ისევ გაუშვი (მონაცემებს არ შლის).

**2.5 Edge Functions.** Edge Functions → **Deploy a new function** → **Via Editor**:
- `game`: შაბლონის კოდი წაშალე, ჩასვი `supabase/functions/game/index.ts` (GitHub-ზე იგივე **Copy raw file**),
  ქვემოთ სახელი: `game` → **Deploy function**.
- `push`: იგივე `supabase/functions/push/index.ts`-ით, სახელი: `push`.
- ორივე ფუნქციის გვერდზე (Details / Settings) **JWT-ის შემოწმება გამორთე** და შეინახე.
  `push`-ს ბაზა იძახებს საიდუმლო სათაურით, `game` კი მომხმარებელს თავად ამოწმებს — ასე ახალ გასაღებებთანაც მუშაობს.

**2.6 ავტორიზაცია.**
- Authentication → Sign In / Providers → **Email**: სატესტოდ გამორთე **Confirm email**. Supabase-ის ჩაშენებული
  ფოსტა წერილს მხოლოდ შენი ორგანიზაციის წევრებს უგზავნის — სხვები დადასტურების წერილს ვერ მიიღებენ.
  რეალური გაშვებისთვის: Authentication → Emails → **SMTP Settings** → უფასო Resend ან Brevo, მერე Confirm email ისევ ჩართე.
- Multi-Factor → **TOTP** ჩართული უნდა იყოს (ნაგულისხმევად ჩართულია). ვისაც 2FA აქვს, კოდის შეყვანამდე
  მესიჯებს, შეტყობინებებს და პირად მონაცემებს ბაზა არ აჩვენებს.
- URL Configuration — იხ. ნაბიჯი 4 (Vercel-ის მისამართი დაგჭირდება).

**2.7 გასაღებები Vercel-ისთვის.** ზედა ზოლში **Connect** (ან Project Settings → API Keys):

### 3. Vercel — საიტი

1. vercel.com → **Add New… → Project** → Import Git Repository → `bakakuri/ezo` → **Import**.
   თუ სიაში არ ჩანს: **Adjust GitHub App Permissions** → Vercel-ს მიეცი წვდომა `ezo` რეპოზე.
2. Framework Preset: **Vite** (თავისით ცნობს). Build Command `npm run build`, Output `dist` — არაფერი შეცვალო.
3. **Environment Variables** (Deploy-მდე!):
   - `VITE_SUPABASE_URL` = Project URL
   - `VITE_SUPABASE_ANON_KEY` = Publishable key
   - `VITE_VAPID_PUBLIC_KEY` = `ezo-push-keys.txt`-დან (თუ Push-ს ჩართავ)
   - `VITE_TURN_URLS`, `VITE_TURN_USERNAME`, `VITE_TURN_CREDENTIAL` — ზარებისთვის, არასავალდებულო (იხ. ქვემოთ)
4. **Deploy** → 1–2 წუთი → მიიღებ მისამართს, მაგ. `ezo-xxxx.vercel.app`. სახელის შეცვლა: Settings → Domains.
5. ცვლადს თუ მოგვიანებით დაამატებ ან შეცვლი: Deployments → ბოლო → **⋯ → Redeploy** (`VITE_` ცვლადები აწყობისას ჩაიწერება).

ბმულის ბარათებს (Facebook, Telegram…) `api/og.js` აკეთებს იმავე ორი ცვლადით — დამატებით არაფერი სჭირდება.

### 4. Supabase-ში დაბრუნება — მისამართები

Authentication → **URL Configuration**:
- Site URL: `https://შენი-მისამართი.vercel.app`
- Redirect URLs → Add URL: `https://შენი-მისამართი.vercel.app/**` → Save.

ამის გარეშე პაროლის აღდგენის და Google-ით შესვლის ბმულები localhost-ზე გადაგიყვანს.

### 5. Push შეტყობინებები (არასავალდებულო)

ყველაფერი `ezo-push-keys.txt`-შია (ცალკე გამოგიგზავნე, **რეპოში არ ჩადო**):
1. Edge Functions → **Secrets**: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `PUSH_SECRET`.
2. SQL Editor: ფაილის `insert into public.app_secrets …` ბრძანება — `PROJECT_REF` შეცვალე შენი `<ref>`-ით.
3. Vercel: `VITE_VAPID_PUBLIC_KEY` → Redeploy.
4. აპში: პარამეტრები → „შეტყობინებები ტელეფონზე“. Android Chrome-ზე პირდაპირ მუშაობს,
   iPhone-ზე — მხოლოდ მაშინ, თუ ეზო მთავარ ეკრანზეა დამატებული.

### 6. პირველი შესვლა და ადმინი

ტურნირების ტაიმერი pg_cron-ით თავისით ირთვება (ნაბიჯი 2.3).

- საიტი იხსნება, რეგისტრაცია და პოსტი მუშაობს.

### ზარები და TURN
Wi-Fi-ზე ზარი STUN-ითაც მუშაობს, მაგრამ მობილურ ინტერნეტზე ოპერატორები ხშირად პირდაპირ კავშირს ბლოკავენ
და საჭიროა TURN სერვერი. უფასო ლიმიტით შეგიძლია აიღო, მაგალითად, Metered-ზე ან Cloudflare Realtime-ზე, და
მისამართი/მომხმარებელი/პაროლი ჩაწერო Vercel-ის სამ `VITE_TURN_*` ცვლადში. სიგნალები Supabase Realtime-ით მიდის.

### დემო რეჟიმი
Supabase-ის გასაღებების გარეშე აპი **დემო რეჟიმში** ირთვება: მონაცემები მეხსიერებაშია, ჩატში პასუხობენ,
თამაშებში კომპიუტერი გეთამაშება, მოდერაციის პანელიც ჩანს. კარგია დიზაინის სანახავად.
